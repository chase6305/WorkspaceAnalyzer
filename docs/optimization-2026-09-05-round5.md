# 第五轮：可达性与灵巧度测试扩展

日期：2026-09-05。本轮根据进一步完善机器人可达性和灵活性测试的要求，完成了
任意目标评估接口、质量报告、命令行入口与解析回归基准。

## 新增能力

- `ReachabilityConfig` 和 `WorkspaceAnalyzer.analyze_targets`：支持单个或批量
  位置/位姿目标、任务权重、输入坐标变换、逐目标初值、分批求解、取消与缓存。
- 输出分别记录 IK 成功和质量达标。成功配置计算操纵度、最小奇异值、各向同性、
  条件数、关节限位余量及任务秩；所有返回配置保留独立位置误差，位姿任务另有
  弧度制旋转误差。
- 可配置最小奇异值、最小各向同性、最小关节余量，以及完整任务满秩要求。统计
  各阈值失败数量和去重后的质量拒绝数量，支持原始及加权达标率。
- CLI 增加 `--mode targets`，读取 CSV/NPY/NPZ，输出结果 NPZ 与 JSON 报告。
  Viser 面板分别显示 IK 成功和质量达标数量。
- `AnalysisResult.target_poses` 可选保存完整目标位姿；原版本无该字段的 NPZ
  继续可读。JSON 中用 `null` 与计数表达无数据及非有限统计，不写入 NaN/Infinity。
- 内置三轴平移机构与五目标 CSV 示例，见 [测试指南](reachability-testing.md)。

## 正确性与计算优化

整数或整数列表构造的 `CartesianConfig.reference_pose` 原先会让批内齐次矩阵
保持整数类型，小数 XYZ 写入后被截断。现在统一保存浮点位姿，并复制配置中的
边界、位姿和初值为只读快照，避免调用者修改原数组影响正在运行的测试或缓存键。

新目标评估仅对 IK 成功配置计算灵巧度，并复用同时计算出的 FK/Jacobian，避免
为了位置诊断与灵巧度重复遍历运动链。失败配置仅计算用于误差诊断的 FK，质量
指标保持 NaN。质量分位数合并计算；缓存中目标、初值和任务权重使用二进制
摘要，避免先生成大量 Python 列表对象。

针对任务维度不足的问题，额外报告 `task_rank` 并提供满秩要求。比如三轴平移
机构的六维 Jacobian 紧致奇异值可以全为 1，但秩只有 3，不能通过完整六维任务
的满秩检查；平面二连杆的非奇异配置也不能据此宣称完整三维位置可控。

本轮没有测量或宣称整体 IK 加速比例。输入输出仍为完整数组；目标变换后按批
求解，尚未实现增量输出或断点续算。

## 验证

完整测试 **291 passed**，较上一轮增加 50 项。新增验证包括：

- 三轴平移机构的解析可达范围、单位位置 Jacobian、限位余量与任务权重统计。
- 平面二连杆的伸直奇异位形、弯曲位形与范围外目标。
- NumPy/Torch CPU，float32/float64；单目标及尾批次；旋转和平移坐标变换。
- 位置可达但姿态无法实现的任务；半周旋转的误差；三轴机构对六维任务的秩亏。
- 全失败任务、无穷条件数、无数据统计、大权重缩放及安全 NPZ 往返。
- 目标、权重、初值、变换和质量配置的缓存区分；首次运行及命中缓存后的取消。
- CSV/NPY/NPZ 命令行输入、JSON 报告和 Viser 中两类判定的显示。
- 整数参考位姿不再截断小数目标，外部数组修改不再改变配置快照。

`ruff check`、`ruff format --check` 与 `git diff --check` 均通过。
sdist 与 wheel 构建通过；wheel 安装到独立临时目录后，在仓库外运行目标模式 CLI，
五目标示例得到预期的 4 个 IK 成功、2 个质量达标，JSON 和 NPZ 往返验证通过。

## Marvin 实际模型检查

使用本机 Marvin M6 URDF、`left_arm_base → left_ee`、NumPy/float64。
固定种子 77，在关节中位附近生成 16 个配置，再由 FK 构造已知可达目标；追加
一个 `[10, 10, 10]` 米的远端目标。求解从默认关节中位开始，批大小 8，初次
4 个起点，失败补救 8 个起点、2 轮。质量要求为各向同性 ≥0.05、关节余量 ≥0.1，
灵巧度任务选择 position。

| 模式 | 已知可达目标求解成功 | 远端目标 | 质量达标 | 成功目标最大位置误差 |
| --- | --- | --- | --- | --- |
| 位置约束 | 16/16 | IK 失败 | 13/17 | 4.58e-6 m |
| 完整位姿约束 | 16/16 | IK 失败 | 13/17 | 3.12e-6 m |

报告：`/tmp/workspace-analyzer-round5-marvin-report.json`。
结果：`/tmp/workspace-analyzer-round5-marvin-position.npz` 与
`/tmp/workspace-analyzer-round5-marvin-pose.npz`。
这些是小规模回归样例，不能代表整台机器人的整体可达率或全姿态覆盖率。
