# 第十二轮：退化区域采样与数值稳定性

日期：2026-09-08。

## 改动

- `CartesianConfig` 接受相等上下界，直接表达平面、线段和固定点；仍拒绝
  反向区间和非有限坐标。CLI 使用同一规则，并补充帮助及中英文说明。
- 采样仅在变化轴上执行，固定坐标精确保留。均匀网格的层数按变化轴数量
  计算，避免把固定轴展开成重复层；随机、Gaussian、Halton、Sobol、LHS
  与直接采样降维区间得到相同序列。全部坐标固定时返回请求数量的同一点。
- 底层 `sample` 通过 `allow_fixed=True` 显式开启固定轴，普通关节采样继续
  要求严格递增区间。原有非退化区间保留采样序列与网格顺序。
- 对宽度超出 float64 范围的有限区间，使用端点凸组合映射，避免
  `upper - lower` 溢出导致无穷大或 NaN；普通区间保留原来的就地映射。
