# 第十六轮：Torch 灵巧度梯度可靠性

日期：2026-09-08。

## 问题与修复

原实现通过 `torch.where` 选择各向同性和条件数的有效分支，但两侧表达式
都会计算。零 Jacobian 产生未选中的 `0/0`，秩不足产生未选中的非零数除零。
前向输出虽然是预期的 0 或无穷大，反向传播仍可能被 NaN 污染。
即使用户对无穷条件数做 `torch.isfinite` 屏蔽，问题也会发生。

本轮先为未选中的分支设置非零除数，再执行除法和选择。零 Jacobian 的
各向同性仍为 0，数值秩不足的条件数仍为无穷大，正常构型的公式与秩阈值不变。
屏蔽分支对有限损失贡献零梯度，不改变正常分支的解析导数。

## 可复现反例

位置 Jacobian 为对角矩阵，其他三行均为零。
下表记录对有限值求和后，反向传播的 Jacobian 梯度是否全部有限。

| 对角元素 | 指标 | 前向值 | 修复前 | 修复后 |
| --- | --- | ---: | --- | --- |
| `[0, 0, 0]` | 各向同性 | 0 | 含 NaN | 全部有限 |
| `[0, 0, 0]` | 条件数 | ∞ | 含 NaN | 全部有限 |
| `[2, 1, 0]` | 条件数 | ∞ | 含 NaN | 全部有限 |
| `[3, 2, 1]` | 各向同性 | 1/3 | 全部有限 | 全部有限 |
| `[3, 2, 1]` | 条件数 | 3 | 全部有限 | 全部有限 |

完整回归可执行：

```bash
PYTHONPATH=src python -m pytest -q tests/test_metrics_gradients.py
```
