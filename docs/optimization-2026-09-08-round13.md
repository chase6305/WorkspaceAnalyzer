# 第十三轮：候选分析性能与测量校验

日期：2026-09-08。

## 改动

候选选择和配置多样性分析原先调用完整质量重评来验证每组试验的通过标记，
因此重复计算全部质量分位数和残差统计，并复制报告元数据。
本轮拆出共用输入校验和质量门槛判断：候选校验只重建通过标记，完整重评
继续计算报告，候选选择只为最终输出生成一次报告。旧标记与当前测量冲突时
仍然拒绝分析；门槛、任务权重、残差和额外指标的类型与形状均继续检查。

选择结果汇集改为每组选中行索引只生成一次，复用于关节、残差和全部指标，
没有选中候选的试验直接跳过。返回结果继续拥有独立数组，保留全部选择来源。

新增 `examples/benchmark_candidates.py`，可调目标数、试验数、重复次数，并输出
计时及结果摘要。使用解析冗余平移机构的已测记录重复构造输入，计时不含
IK 和输入构建，不能用于评价机器人可达率或 IK 求解速度。

## 本机性能对照

3 万目标、12 组试验，每项运行 5 次取中位数；单位为毫秒。

| 操作 | 改动前 | 改动后 | 加速比 |
| --- | ---: | ---: | ---: |
| 候选校验 | 16.48 | 4.45 | 3.7× |
| 候选选择（含校验） | 21.22 | 9.96 | 2.1× |
| 配置多样性（含校验） | 29.04 | 19.82 | 1.5× |

这是短时合成测例，绝对时间和加速比会随机器负载、目标数及候选分布变化。
选中结果的全部测量数组、指标与完整元数据，以及完整多样性报告，前后 SHA-256
摘要均一致。原始记录在 `outputs/round13-candidates/before.json` 和 `after.json`。

复现当前版本：

```bash
PYTHONPATH=src python examples/benchmark_candidates.py \
  --targets 30000 --trials 12 --repeats 5 \
  --output outputs/round13-candidates/after.json
```
