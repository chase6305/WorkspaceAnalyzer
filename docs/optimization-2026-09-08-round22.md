# 第二十二轮：研究目录与初值来源校验

日期：2026-09-08。

研究目录加载原先直接假定 JSON 是对象且包含合法试验条目，异常结构可能导致
AttributeError 或 KeyError。初值形状只与报告比对，即使文件与报告同时改成
错误的自由度或目标数，也可能被加载为合法来源记录。

本轮在数组读取前检查报告对象、整数版本、至少两个试验、非空唯一名称及初始化
结构。初值归档中的损坏 ZIP/DEFLATE、缺失成员和 NPY 误传得到明确的 ValueError。
加载仍使用固定试验文件名，不将报告中的展示名称作为路径。

共用兼容性检查同时核对初值有限性、实数类型与实际 `(DoF,)`、`(1, DoF)` 或
`(N, DoF)` 形状。初值来源被调用者修改后，报告、保存、候选选择和多样性分析
均会验证；非法来源不会先写出研究目录。正常只读初值、混合精度及保存加载行为保留。

新增 17 项回归：

- 八种非法报告，包括非对象 JSON、布尔版本、空试验、非法条目与重复名称，
  均在读取数组前拒绝。
- 缺少初值成员、NPY 误传、截断归档及与测量不符的自由度/目标数得到明确错误。
- 非有限、复数和错误形状的公共初值记录不能进入报告、保存或候选分析。

全量 pytest：686 passed、4 skipped。Ruff、51 个 Python 文件格式、完整解析
工作流、sdist/wheel 构建及 `git diff --check` 通过。

本轮没有运行 CUDA 或远程 CI；没有提交或推送。
