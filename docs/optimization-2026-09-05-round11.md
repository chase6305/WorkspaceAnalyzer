# 第十一轮：候选初值生成与配置多样性

日期：2026-09-05。本轮把“增加求解试验”进一步区分为新增配置、重复候选和新增
达标配置，为评估初值预算是否有效提供可复查的数据。

## 完成内容

- 新增 `make_ik_seed_trials`，在求解器关节区间内生成固定种子的均匀初值。
  独立随机数流不影响目标采样和 IK 重启，初值只读并保持求解精度；增加生成
  数量时，已有向量序列的前缀不变。
- 新增 `IKDiversityConfig`、`summarize_ik_diversity` 和对应 study 方法，按目标
  分组，记录每组试验的新增配置、重复候选、新增达标组和代表试验索引。
- 转动与移动关节分别使用弧度和米容差，仅连续关节采用模 `2π` 的最短角距离。
  新试验保存关节类型，旧结果可显式指定类型进行离线分析。
- 分组保留全部候选。靠近质量门槛两侧的配置即使归入同一组，也分别参与质量
  筛选；只要一个成员达标，该组就计为包含达标配置。
- 分组与选择共用候选数据校验，检查残差、成功配置、质量标记和试验兼容性。
  配置分组不运行 IK/FK/Jacobian，也不修改原始测量。
- 工作流增加显式初值数量、配置多样性开关及角度/距离容差，保存独立 JSON 与
  Markdown 统计。Make 和可选运行时 CI 配置已接入，原验收条件继续生效。

## 解析二连杆：自动初值找到达标配置

使用 `tests/fixtures/two_branch.urdf`，目标为 `(1, 1, 0)` 和故意构造的范围外
位置 `(5, 5, 0)`。基准初值为靠近肘限位的 `(π/2, -π/2)`，另外用生成器种子
77 在完整关节区间生成 4 个初值。每组最多 100 次迭代，restarts 为 1，不启用
失败补救。任务仅约束位置，各向同性门槛为 0.05，关节余量门槛为 0.2。

| 指标 | 结果 |
| --- | --- |
| 试验 / 目标数 | 5 组 / 2 个目标，共 10 次目标评估 |
| `(1, 1, 0)` IK 成功次数 | 5 次 |
| 当前容差下该目标的配置组数 | 2 组，3 次重复候选 |
| 生成初值找到的达标配置 | 4 次成功均达标，属于同一个配置组 |
| 基准 / 选定配置关节余量 | 0.01460184 / 0.41460008 |
| 选择后 IK / 质量通过目标数 | 均为 1/2；范围外目标仍失败 |

通过独立三角公式 `x=cos(a)+cos(a+b)`、`y=sin(a)+sin(a+b)` 复查选定配置，
本地 NumPy/float64 记录的位置误差约 `2.49e-6 m`，低于 `1e-5` 的 IK 容差。
与上一轮手工给出两个已知解的试验相比，本轮达标解来自自动生成初值后的求解。

原始初值、各组配置、选择结果和摘要保存在 `outputs/round11-analytic-diversity/`。

## Marvin：成功次数与配置数量的区别

输入继续使用第九轮四个最终边界端点，对应第八轮测量行 `[16, 18, 15, 19]`。
本轮重新运行默认初值基准及 8 个生成初值，共 **9 组、36 次目标评估**。

共同配置：Marvin `left_arm_base → left_ee`，NumPy/float64，最大迭代 150，
batch size 16，16 个重启、失败补救 32 个重启共 2 轮，重启种子 77。初值生成器
种子也为 77，但使用独立随机数流，范围为完整关节代表区间。保持完整位姿约束
及原来的各向同性 0.05、关节余量 0.1 门槛。配置分组使用 0.001 rad 角容差。

## 范围与下一步

配置组依赖关节容差和试验顺序，不是全部分支枚举。近似关系不具有传递性，
代表分组也不用于删除候选；一个接近代表的成员可能刚好通过质量门槛。

生成器提供均匀初值，不按质量梯度定向搜索，也不保存求解器内部全部重启候选。
下一步可增加区域多区间发现，或针对质量不足目标比较局部候选生成策略，验收
新增达标配置与实际预算开销。碰撞、连续路径有效性与大规模流式存储仍属后续范围。

使用方法见 [初值与多样性指南](candidate-diversity.md)，后续验证方案见
[验证方案分析](validation-options.md)。
