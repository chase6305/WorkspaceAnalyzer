# 第二十轮：跨试验初值预检查

日期：2026-09-08。

稳定性分析原先只提前检查全部初值的形状，而精度转换有效性检查发生在每组
试验开始时。如果第二组初值在 float32 中溢出，第一组仍会先求解和写入缓存。

本轮将全部初值在求解器精度下的有限性检查前移至任何试验求解和缓存访问之前，
并在逐组检查期间响应取消。原始只读初值快照保持不变，实际计算仍按求解器
精度转换；保存和来源追溯继续保留用户提供的原始精度。

同时将取消事件传入最终兼容性检查，并在返回前再检查一次，避免取消后仍返回
完整研究对象。此次没有将整项研究的缓存写入改为事务，也不会回滚取消前已完成
试验的有效缓存。

验证新增 9 项回归：

- NumPy/Torch CPU 的 float32 研究中，后续 `(DoF,)`、`(1, DoF)`、`(N, DoF)`
  初值溢出均在首次求解、缓存访问和进度回调前失败。
- 两个后端的有效 float64 初值用于 float32 求解时，原始初值精度、数值与
  保存加载结果保持一致。
- 最终兼容性检查收到取消后在首组检查结束时中止。

工作流、sdist/wheel 构建及 `git diff --check` 通过。
