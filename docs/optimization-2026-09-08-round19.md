# 第十九轮：跳过多样性分组的无效比较

日期：2026-09-08。

## 改动

原有配置分组对每个新试验扫描全部历史试验。没有产生任何代表配置的试验
不可能匹配后续候选，当前成功候选已经全部匹配后，继续扫描也没有作用。

本轮按原始顺序维护实际产生过代表配置的试验索引，并在当前候选全部匹配后
停止比较。每目标仍选择最早的匹配代表，保留原有非传递、顺序相关的分组语义。
原始测量不删除，重复候选通过质量门槛时仍可为其配置组增加达标贡献。

周期关节判断移出内层循环；高级索引产生的独立 float64 数组直接使用，避免
再次复制。float32 候选仍在比较前转换为 float64，继续采用各自的角度/距离容差。

## 本机性能对照

3 万目标、128 组试验，重复解析冗余平移机构的两组记录；每项运行 5 次取中位数。

| 多样性分析（含校验与报告） | 改动前 | 改动后 |
| --- | ---: | ---: |
| 中位耗时 | 236.96 ms | 177.36 ms |

此重复候选测例耗时减少约 25%。完整多样性报告 SHA-256 前后均为：
`5dccd1a93a4a92fb46116f16245dbc91f3a265e8a488a4c6365c6827d6740543`。
候选选择和稳定性报告摘要也保持一致。绝对时间受机器负载影响；大量不同配置
时最坏复杂度仍为二次比较，不是全部 IK 分支枚举。

原始记录位于 `outputs/round19-diversity/before.json` 和 `after.json`。

```bash
PYTHONPATH=src python examples/benchmark_candidates.py \
  --targets 30000 --trials 128 --repeats 5 \
  --output outputs/round19-diversity/after.json
```
