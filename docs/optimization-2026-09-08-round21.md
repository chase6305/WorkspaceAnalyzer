# 第二十一轮：损坏缓存的恢复路径

日期：2026-09-08。

## 问题与改动

复现了 ZIP 目录完整但 DEFLATE 数据损坏的缓存：读取抛出 `zlib.error`，
原缓存恢复逻辑没有识别这个异常，导致分析直接中断。

结果加载现在将损坏 ZIP、截断数据、DEFLATE 错误及缺少必要数组统一转换为
带原因链的 `ValueError`。缓存据此返回未命中，分析器重新计算并原子替换文件。
直接误传 NPY 数组文件也会收到明确的格式错误。文件不存在等文件系统错误
继续保留原类型，读取继续禁用 pickle。

缓存键验证先检查字符串类型，再检查小写 SHA-256 格式；None、整数、字节串、
列表或数组不会再触发不相关的类型错误或数组真值歧义。
