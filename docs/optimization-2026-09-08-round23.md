# 第二十三轮：派生质量报告的一致性

日期：2026-09-08。

姿态覆盖、扰动和稳定性报告原先只校验质量标记形状及“达标必然 IK 成功”，
没有复核标记与当前测量及门槛的一致性。手动修改指标、门槛或成功配置上的
质量标记后，报告可能继续使用过期判定。

本轮引入共用的已存质量标记检查：要求完整门槛，按当前测量重新计算通过标记，
发现不一致时明确要求先重评。校验只计算门槛，不重建分位数或完整评估报告。
候选选择与多样性分析复用稳定性兼容性检查，移除原先重复的门槛复核。

显式 `reassess_quality(...)` 后，可继续生成覆盖率、配对扰动统计或稳定性报告；
原始测量和标记不会被隐式修改。质量门槛参数仍采用完整替换语义。

新增 9 项回归，覆盖三类报告与三种修改：

- 成功配置的指标改为正无穷大。
- 直接修改已存的质量标记。
- 修改质量门槛，使已存标记与当前指标不符。

各路径均拒绝过期结果，显式重评后可以生成严格 JSON 报告；原结果继续保持
原状。测试同时确认一致性检查不调用完整统计报告生成函数。

全量 pytest：695 passed、4 skipped。Ruff、51 个 Python 文件格式、完整解析
工作流、sdist/wheel 构建及 `git diff --check` 通过。

本轮没有运行 CUDA 或远程 CI；没有提交或推送。
