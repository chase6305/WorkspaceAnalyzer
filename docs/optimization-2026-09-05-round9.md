## Marvin 边界端点复查

目标取自 `outputs/round8-marvin-boundary/measurements.npz` 的最终端点，按每条
线段成功端、失败端排列，对应测量行 `[16, 18, 15, 19]`。两条线段分别来自原始
参考 11、12，均为零基索引。全部试验使用相同四个位姿和完整姿态约束。

共同配置：Marvin `left_arm_base → left_ee`，NumPy/float64，batch size 16，
16 个重启、失败补救 32 个重启共 2 轮。质量门槛继续使用位置 Jacobian 各向同性
0.05、关节余量 0.1。

交叉组合 **150/400 次迭代 × 随机种子 77/78 × 默认/邻近成功配置初值**，共
8 组、32 次目标评估。邻近初值取上一轮对应线段的最终成功端配置，同一条线段
的两个端点使用相同初值。各组不继承其他试验的解。

| 目标 | 8 组 IK 成功次数 | 8 组质量通过次数 | 成功配置关节余量范围 |
| --- | ---: | ---: | ---: |
| 参考 11 成功端 | 8 | 0 | 0.22627–0.30818 |
| 参考 11 失败端 | 0 | 0 | 无成功配置 |
| 参考 12 成功端 | 8 | 0 | **0.00166–0.66857** |
| 参考 12 失败端 | 0 | 0 | 无成功配置 |

本次 IK 分类分歧率为 0。两个失败端的残差分别约为 `3.30e-5`、`1.55e-5`，
两个成功端的残差均低于 `3.70e-6`；这些是完整位姿任务的混合残差，不能直接
解释为米。成功配置各向同性分别为约 0.01324–0.01329、0.03040–0.03297，均未
达到原质量门槛，因此没有修改门槛来改变验收结果。

参考 12 成功端表明：即使所有试验都判定 IK 成功，返回关节配置的质量仍可能
明显变化。本次质量标记也全部一致，但指标并不稳定。该结果支持后续验证多候选
解的质量选择；当前接口只比较原始测量，不合并或宣称找到最佳解。

保存目录为 `outputs/round9-marvin-stability/`，包含 `report.json`、
`trial_000.npz` 至 `trial_007.npz`、`initial_seeds.npz` 和额外记录来源行号的
`source_rows.npz`。下面可复查原始摘要：
