# 第十四轮：稳定性报告内存与取消响应

日期：2026-09-08。

## 改动

- 稳定性报告按试验逐组累积残差、各向同性与关节余量的有限计数及极值，
  替代完整浮点矩阵和同尺寸的条件替换临时数组。数值工作数组只随目标数增长。
- 极值数组批量转换为 JSON 可用的浮点数和 `None`，避免逐元素调用 NumPy
  有限性检查。失败目标的有限残差仍参与残差统计；质量指标只统计 IK 成功项。
- `IKStabilityResult.to_dict(cancel_event=...)` 支持取消，兼容性检查、逐组
  对比、指标累积和返回前均检查事件；取消不修改源测量或返回部分报告。
- 候选选择和多样性分析向共用兼容性检查传递取消事件，避免先扫完全部试验。
- 兼容性检查明确拒绝形状错误、复数或布尔残差，避免广播或迟发类型错误。
- 基准脚本增加稳定性报告摘要及可选峰值分配跟踪；计时与内存测量分开执行。

## 本机对照

使用 3 万目标、64 组试验，各计时运行 5 次取中位数。
输入为重复的解析冗余平移机构测量，计时不含 IK 和输入构建。

| 稳定性报告 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 中位耗时 | 80.77 ms | 21.81 ms |
| 峰值跟踪分配 | 43,746,398 bytes | 12,623,184 bytes |

此测例约快 3.7 倍，峰值跟踪分配减少约 71%。跟踪分配使用 `tracemalloc`，
并非进程 RSS，也不包含预先构建的输入存储；绝对时间随机器负载变化。
完整稳定性报告 SHA-256 前后相同，候选选择和多样性报告摘要也保持一致。
原始数据在 `outputs/round14-stability/before.json` 与 `after.json`。

复现当前版本：

```bash
PYTHONPATH=src python examples/benchmark_candidates.py \
  --targets 30000 --trials 64 --repeats 5 --measure-memory \
  --output outputs/round14-stability/after.json
```

原始试验、布尔状态矩阵和最终报告仍需内存；本轮没有实现磁盘流式处理。
