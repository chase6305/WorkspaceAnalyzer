# 第十七轮：非有限质量测量的达标判定

日期：2026-09-08。

## 问题与改动

原先质量门槛直接使用 `measurement >= threshold`。正无穷大因此可以通过
最小奇异值、各向同性和关节余量门槛，即使该值来自数值溢出或外部编辑。
本轮将启用的门槛统一改为“指标有限且大于或等于门槛”。

原始测量、IK 成功标记、残差与统计中的无穷计数继续保留。关闭某指标门槛时，
该指标不参与质量筛选。秩亏条件数仍允许为无穷大，没有改成有限值或另加门槛。

新评估、离线质量重评、缓存重放及候选校验共用判定函数。缓存保存的是测量，
无需因为此次判定修正重跑 IK。旧候选池若含正无穷且保留达标标记，会报过期
质量标记；明确提供完整门槛重评后，可继续从有限达标候选中选择。

## 验证

三种门槛分别覆盖以下路径，新增 12 项回归：

- 有限值恰等于门槛通过，略低于门槛失败；NaN、正无穷和负无穷均失败。
- 原始 IK 分类与异常测量保留，阈值失败数和加权达标率准确，关闭门槛行为一致。
- 模拟在线质量计算溢出，确认成功 IK 配置不会因正无穷而达标。
- 保存含异常测量的缓存，禁用 IK/FK/Jacobian 后仍能按新门槛正确重评。
- 候选选择及多样性分析拒绝过期达标标记；重评后选出有限达标候选。
